FaceRiff generates complete 3D face assets directly from text: a mesh, lighting-independent albedo, and fine-scale displacement, all aligned in a shared UV space. It adapts a pretrained SDXL diffusion model using task-specific LoRA adapters and UV normal maps for geometric conditioning.

Trained on 2,049 scans from approximately 350 identities using a single GPU, the framework updates less than 3% of the backbone parameters per task and produces assets ready for rendering without per-instance optimization.
